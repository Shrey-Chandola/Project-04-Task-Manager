# Task Manager

A responsive Task Manager web application built using HTML, CSS, and vanilla JavaScript.

This project was created as a learning project to practice DOM manipulation, JavaScript event handling, CSS Grid, Flexbox, filtering, browser storage, and responsive UI development.

## Features

- Add new tasks
- Mark tasks as completed or active
- Delete individual tasks
- Filter tasks by:
  - All
  - Active
  - Completed
- Clear all completed tasks
- Display active task count
- Automatic task numbering
- Empty-state messages for empty task lists
- Prevent empty or whitespace-only tasks
- Add tasks using the Enter key
- Persist tasks using Local Storage
- Restore tasks after page refresh
- Responsive layout for mobile, tablet, and desktop screens
- Complete and delete actions using icons
- Hover effects and transitions

## Technologies Used

- HTML5
- CSS3
- JavaScript (ES6+)
- DOM Manipulation
- CSS Grid
- Flexbox
- Local Storage
- JSON
- Font Awesome
